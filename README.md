# Battle Desk v7

GitHub Pages용 전투 관리 프로그램입니다.

## v7 변경사항
- 버튼 이벤트 초기화 구조를 안전하게 정리하여 버튼 미작동 가능성을 줄였습니다.
- 정적 버튼은 존재 여부를 확인한 뒤 이벤트를 등록합니다.
- 동적 전투 카드 버튼은 이벤트 위임으로 처리합니다.
- 전체 캐릭터 목록에만 진영 필터를 표시합니다.
- 전투 인원 영역의 진영 필터를 삭제했습니다.
- 전체 캐릭터 목록 필터는 `전체 / 진영 A / 진영 B`로 동작합니다.
- 저장 키를 v7로 변경하고 v6 이하 저장 데이터도 자동 마이그레이션합니다.
- JS 파일에 버전 쿼리를 붙여 GitHub Pages 브라우저 캐시로 인한 구버전 로딩 가능성을 줄였습니다.
