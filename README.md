# Battle Desk v2

GitHub Pages용 정적 전투 시뮬레이터입니다. `index.html`, `css/style.css`, `js/app.js`를 저장소 루트에 업로드하면 됩니다.

## 반영한 기능
- 기본 능력치 5종: 최대 HP, 공격, 치유, 방어, 민첩
- 능력치 테이블에 커스텀 항목 추가 및 삭제, 8단계 값 편집
- 주사위식 `NdM`, `NdM+보정`, `NdM-보정` 지원
- 전체 캐릭터 목록과 전투 인원 목록 분리
- 민첩순 선공과 매 턴 민첩 대항 선공 선택
- 민첩 대항은 각 캐릭터의 민첩값을 최대치로 하는 주사위 굴림이며 동률 시 재판정
- 방어는 방어 주사위 결과만큼 공격 피해 경감
- 반격은 능력치 추가에서 이름을 `반격`으로 등록하면 반격 주사위만큼 상대 공격을 경감하고 같은 값만큼 상대에게 피해
- 치유 주사위로 대상 HP 회복
- JSON 백업/불러오기, 전투 로그 내보내기, 브라우저 자동 저장

## 배포
GitHub 저장소의 `Settings → Pages → Deploy from a branch`에서 `main`과 `/(root)`를 선택하세요.

## 참고
이 버전은 원래 Battle Desk 소스의 화면 스타일을 유지하면서 요청한 전투 규칙을 추가한 재구성 버전입니다. 기존 v1의 저장 데이터와는 별도 키를 사용합니다.
