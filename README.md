# Battle Desk · 커스텀 전투 시뮬레이터

GitHub Pages에서 바로 배포할 수 있는 정적 웹사이트입니다. 별도의 서버, 빌드 도구, 외부 라이브러리가 필요하지 않습니다.

## 파일 구성

```text
battle-assist-custom/
├─ index.html
├─ css/
│  └─ style.css
├─ js/
│  └─ app.js
└─ README.md
```

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더 안의 `index.html`, `css`, `js`, `README.md`를 저장소 루트에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**에서 `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, 폴더는 `/ (root)`로 설정하고 저장합니다.
6. 잠시 후 표시되는 Pages 주소로 접속합니다.

## 기능

- 캐릭터 생성 및 A 진영 / B 진영 / 중립 분류
- 등급별 HP, 공격 주사위, 방어율, 회피율, INT 배율 편집
- 민첩순 정렬 및 턴 진행
- 대상 선택 공격, 방어·회피 반응, 회복, 도주
- 진영 기반 승리 판정 (A/B 진영이 모두 존재할 때)
- 전투 로그 TXT 추출 및 클립보드 복사
- JSON 백업 내보내기 / 불러오기
- 브라우저 로컬 저장소 자동 저장
- 마지막 행동 되돌리기
- 데스크톱·모바일 반응형 레이아웃

## 전투 규칙

기본 능력치 표는 원본 BattleAssist의 초기값을 바탕으로 했습니다.

- 공격 주사위 표기는 `1d6`, `2d8`처럼 `NdM` 형식을 사용합니다. 숫자만 입력하면 고정 공격력으로 처리합니다.
- 피해량은 `반올림(주사위 합 × 공격자의 INT 배율)`입니다.
- 방어와 회피는 1~100 주사위 판정이며, 굴림값이 설정된 성공률 이하이면 피해를 무효화합니다.
- 도주 성공률은 `민첩 등급 회피율 + 도주 보정치`이며 0~100%로 제한됩니다.
- A와 B 진영이 모두 존재하면 한쪽 진영의 생존자가 없어질 때 승패를 판정합니다. 그렇지 않으면 전체 생존자가 1명 이하일 때 종료합니다.

## 데이터 저장 안내

캐릭터 및 설정은 현재 브라우저의 `localStorage`에 저장됩니다. 브라우저 데이터를 삭제하거나 다른 기기를 사용하면 자동으로 옮겨지지 않으므로 JSON 백업을 이용하세요.
