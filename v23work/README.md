# Battle Desk v11

GitHub Pages용 정적 전투 시뮬레이터입니다.

## 이번 버전 변경 사항
- 선공 방식 `매 턴 민첩 대항 판정`을 `민첩 다이스`로 변경.
- 민첩 스탯 기본값을 1~5로 변경.
- `민첩 다이스`는 매 라운드 시작 전에 전원의 `1d민첩 스탯`을 굴리고 높은 순으로 해당 라운드의 턴 순서를 결정.
- 민첩 다이스가 동률이면 해당 인원끼리 재판정.
- 라운드제와 턴제를 결합. 한 라운드에서 전원의 턴이 끝나면 다음 라운드의 선공 판정을 다시 진행.
- 전투 카드의 일반 진영 텍스트를 제거하고 색상 태그만 유지.
- 공격 빨강, 방어 파랑, 회복 초록, 스킬 보라 계열로 행동 버튼 구분.
- A/B 진영별 색상을 컬러 팔레트와 HEX 입력으로 설정 가능.
- 스킬 버튼 추가. 스킬 효과는 프로그램에서 계산하지 않고 GM 로그만 기록하며 턴을 소모.
- GM 회복 / GM HP 차감 버튼으로 스킬 등 외부 효과를 수동 적용 가능. GM HP 조정은 턴을 소모하지 않음.
- 기존 행운/크리티컬, 방어, 반격 규칙은 유지.

## 배포
`index.html`, `css/style.css`, `js/app.js`, `README.md`를 저장소 루트에 업로드하고 GitHub Pages에서 `main / (root)`로 배포하면 됩니다.
